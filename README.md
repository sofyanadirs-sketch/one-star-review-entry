A deadpan one-star review of sleep, an everyday essential: paid eight hours, woke up tired and late, and somehow still in debt for another eight tonight. Running `main.py` prints that exact line to stdout and writes it, with no trailing newline, to `entry.txt`.

## Run it

```sh
python3 main.py
```
